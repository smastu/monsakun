# モンサクン

モンサクン（和差）の作問画面。各自の Google アカウントでログインして使う。

- 児童・学生用：https://smastu.github.io/monsakun/
- 教員用（課題の作成・ログの CSV 書き出し）：https://smastu.github.io/monsakun/teacher.html
- このリポジトリは配信用で、`index.html`・`teacher.html` は自動生成物（直接編集しない）。
- 操作ログと課題セットは Google Apps Script のウェブアプリが受け取り、教員の Google ドライブに保存する。このリポジトリには個人情報やログは含まれない。
